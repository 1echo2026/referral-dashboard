# 转介绍数据看板

多基地转介绍名单看板：**基地账号登录后只读查看本基地数据，管理员后台维护全部数据与展示配置**。

当前基地：北京、郑州、南京、武汉、合肥、西安、成都、新乡。

## 功能

- 基地账号登录：每个基地一组独立账号，登录后只能看到本基地数据；管理员可查看全部基地。
- 前台总览：时间/来源筛选，KPI、名单趋势、来源结构、基地对比、负责人 Top、基地-负责人下钻。
- 明细名单：搜索、筛选、分页、详情抽屉、脱敏导出。
- 管理后台：首次初始化管理员、登录、数据增删改、Excel/CSV 导入、字段自动映射、校验预览、版本发布/回滚、基地管理、基地账号管理、展示配置、操作日志。
- 数据版本：每次导入生成新版本，前台只读当前版本；切换版本即回滚。
- 隐私保护：前台姓名、手机号默认脱敏；完整信息仅后台可见；备注不在前台展示。
- 零外部服务：Node.js + 内置 SQLite，单机即可运行，适合小团队和基地场景。

## 本地运行

要求 Node.js **22.5+**（使用内置 `node:sqlite`，推荐 Node 24）。

```bash
npm install
npm start
```

- 前台：http://localhost:4310
- 后台：http://localhost:4310/admin
- 首次打开后台会进入“初始化管理员”，创建第一个账号后即可使用。
- 如果忘记管理员密码，可在项目目录运行 `npm run reset-admin`，删除管理员账号后重新初始化。
- 基地账号初始密码在 `data/base-accounts.csv`，请妥善保管；后台「基地账号」可重置密码或停用账号。

可通过环境变量修改端口：

```powershell
$env:PORT=8080; npm start
```

## 导入数据

1. 后台 → 数据导入，选择默认基地和默认来源（表格没有对应列时使用）。
2. 上传 `.xlsx` / `.xls` / `.csv`。
3. 系统自动识别表头，支持的列名包括：
   - 基地：基地、基地名称、所属基地、战区、城市、区域
   - 姓名：客户姓名、姓名、用户姓名、客户名称、联系人
   - 手机号：手机号、手机、电话、联系电话、联系方式
   - 来源：来源类型、名单类型、类型、来源、客户类型
   - 负责人：负责人、跟进人、归属人、销售、顾问、经纪人
   - 状态：状态、跟进状态、转化状态
   - 日期：创建时间、导入时间、日期、名单日期；最近跟进、最后跟进、回访时间
   - 标签 / 备注
4. 校验预览后填写版本名称，选择“追加”或“替换”，发布为新版本。
5. 追加模式会自动跳过“基地 + 姓名 + 手机号 + 来源”完全相同的重复行。

后台导入页提供「下载导入模板」，可直接按模板整理数据。

> 仓库首次启动会自动写入 280 条演示数据，便于查看界面。正式使用前可在后台导入真实名单，或用「替换全部数据」模式发布首期真实数据。

### 从石墨文档导入

原始文档《26年武汉基地-转介绍【新用户直推未转化+高潜老用户名单】明细》如果打不开或要求 Corp 登录，请先在有权限的浏览器中打开石墨表格，选择「导出 / 下载为 Excel」，再上传导出的 `.xlsx`。系统会自动识别常见中文表头。

## 部署到公网

完整的云服务器 + 域名 + HTTPS 部署步骤见 [DEPLOY.md](DEPLOY.md)。

飞书多维表格作为后台的配置见 [FEISHU.md](FEISHU.md)。

### 方式一：Docker（推荐）

```bash
docker compose up -d --build
```

默认映射 `4310` 端口。生产环境建议在前面加 Nginx/Caddy 反向代理并配置 HTTPS 域名。

### 方式二：直接运行 + 反向代理

```bash
PORT=4310 node server.js
```

Nginx 示例：

```nginx
server {
  listen 80;
  server_name dashboard.example.com;
  client_max_body_size 20m;

  location / {
    proxy_pass http://127.0.0.1:4310;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

提示：中国大陆节点需要域名 ICP 备案；使用香港/海外节点可免备案，国内访问速度也可接受。

## 安全说明

- 前台 API 只读，所有写操作都在 `/api/admin/*` 且需要登录。
- 管理员密码使用 scrypt 加盐哈希；会话使用 HMAC 签名 HttpOnly Cookie，8 小时过期。
- 登录接口有基础限流；所有后台写操作写入审计日志。
- 公网展示默认脱敏，若业务确需展示完整手机号，请先评估隐私合规要求。
- 建议生产环境通过环境变量设置固定的 `SESSION_SECRET`（至少 24 位随机字符串），否则会在 `data/.session-secret` 自动生成。

## 数据文件

- `data/dashboard.db`：SQLite 数据库（自动创建并写入演示数据）。
- `data/.session-secret`：会话签名密钥（自动生成，勿提交到代码库）。
- 删除 `data/dashboard.db` 会清空数据并在下次启动时重新生成演示数据。
